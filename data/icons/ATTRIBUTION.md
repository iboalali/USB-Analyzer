# Third-party artwork

## Material Symbols — `cable`

Both application icons draw their glyph from Google's
[Material Symbols](https://fonts.google.com/icons) `cable`, exported at 24 dp,
weight 400, grade 0, fill 0.

- **Files:** `hicolor/scalable/apps/com.iboalali.usbdiag.svg`,
  `hicolor/symbolic/apps/com.iboalali.usbdiag-symbolic.svg`
- **Copyright:** Google LLC
- **Licence:** Apache License 2.0 —
  <https://www.apache.org/licenses/LICENSE-2.0>

The rest of this repository is MIT (see `/LICENSE`). These two are not, which is
why this file exists: Apache 2.0 §4 requires the notice to travel with the work,
and an icon that ships in a `.desktop` entry and a distribution package travels
further than the source tree.

Nothing about the licence needs to change for the project. Apache 2.0 and MIT are
compatible in this direction — an MIT project may include Apache-2.0 material
provided the notice is kept — and only the glyph is Apache-2.0. The surrounding
artwork (the rounded body, the gradient, the palette) is this project's own, and
the path itself is unmodified apart from the `transform` that places it.

### If the glyph is ever replaced

Delete this section along with it. A stale attribution is worse than none: it
credits someone for artwork that is no longer there and misstates the licence of
what is.
